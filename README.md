# Супутники

«Супутники» — это уникальная аркадная игра в космическом сеттинге, которую я разрабатываю в одиночку уже целый год. Проект написан полностью на **нативной Java без использования каких-либо сторонних библиотек и игровых движков**.

## Игровой процесс и особенности

* **Хардкорная разработка:** Никаких тяжелых движков. Чистый код, оптимизация и полный контроль над каждым пикселем.
* **Космический экшен:** Управляй маневренным кораблем с синим энергетическим ядром, используй бустеры и маневрируй среди космических объектов.
* **Уникальный стиль:** Окружение и препятствия стилизованы под развивающиеся флаги различных государств в открытом космосе.
* **Различные режимы:** Несколько игровых режимов, бросающих вызов твоей реакции и точности.

## Технические характеристики

* **Язык программирования:** Java (Native)
* **Минимальная версия Android:** 4.1 (Jelly Bean) — для запуска
* **Рекомендуемая версия Android:** 7.0 (Nougat) и выше — для плавной работы, корректной отрисовки графики и стабильного FPS
* **Совместимость:** Полная поддержка актуальных версий Android 16+





Открой склонированную папку в **Android Studio** и собери проект под свое устройство.
