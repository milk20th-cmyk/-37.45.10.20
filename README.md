# Супутники

Увлекательная аркада, где тебе предстоит отправлять эмодзи стран прямиком в открытый космос.

## Системные требования

* Минимальная версия Android: 4.1 (Jelly Bean) (для запуска)
* Рекомендуемая версия Android: 7.0 (Nougat) и выше (для плавной работы и корректной отрисовки графики)
* Поддержка актуальных версий: Полностью совместимо с Android 16+

## Скачать и установить

Ты можешь скачать последнюю стабильную версию APK прямо со страницы релизов:



1. Скачай актуальный .apk файл из раздела Releases.
2. Разреши установку из неизвестных источников в настройках телефона, если потребуется.
3. Установи и играй.
